## Built With

- **React 19** — Frontend framework

- **Framer Motion** — Animations and transitions
- **Lucide React** — Icon set

## Features

- Fully responsive design (mobile, tablet, desktop)
- Professional identity with structured data (JSON-LD) for search engines
- SEO-optimized metadata (Open Graph, Twitter Cards, canonical URL)
- robots.txt and sitemap.xml for search engine crawling
- Dynamic project portfolio with live demos and source code links
- WhatsApp-integrated contact form
- Interactive professional timeline
- Technology stack showcase
- Lazy-loaded sections for performance

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## SEO & Search Visibility

This portfolio includes:

- **Structured Data (JSON-LD)**: Person, WebSite, and ProfilePage schemas
- **Meta Tags**: Title, description, canonical URL, Open Graph, Twitter Cards
- **robots.txt**: Crawl directives and sitemap reference
- **sitemap.xml**: Page listing for search engine indexing
- **Semantic HTML**: Proper heading hierarchy and accessible markup
